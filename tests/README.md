## grpcurl test

- If you are using a devcontainer, `grpcurl` is available.  
- You can use reflection to test it:  

  ```bash
  grpcurl -plaintext localhost:3000 list
  ```  

- You can also use `grpcurl` to call services. Refer to the documentation: [grpcurl](https://github.com/fullstorydev/grpcurl?tab=readme-ov-file).
